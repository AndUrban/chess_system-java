# Projeto Sistema Jogo de Xadrez - Chess System
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/AndUrban/chess_system-java/blob/main/LICENSE)


# Sobre o projeto

Oferecida pela [DevSuperior](https://devsuperior.com "Site da DevSuperior"),o projeto
consiste em abordar os conceitos de POO (Programação Orientada a Objeto) no desenvolvimento
de um jogo de xadrez - composto por tabuleiro, peças, jogadas, movimentações e regras.
Construtores, sobrecarga, encapsulamento, arrays, listas, enumeração, composição, herança,
polimorfismo, tratamento de exceções, interfaces e classes abstratas; todos os conceitos
citados foram aplicados ao projeto.

# Execução
Pré-requisitos: Java 17

```bash
# clonar repositório:
git clone https://github.com/AndUrban/demo-dao-jdbc

# Dentro da IDE, importar o projeto:
demo-dao-jdbc

# Caminho:
demo-dao-jdbc/src/application/Program.java (Program2.java)
  > Program.java é da entidade Seller; Program2.java é da entidade Department.

# Execute o MySQL Workbench

Conferir as seguintes informações no Workbench e modificar (conforme o necessário) no arquivo db.properties:
> Caminho: demo-dao-jdbc/db.properties
> Atualizar informações:
  user: >seu usuário Workbench<
  password: >sua senha workbench<
  dburl: jdbc:mysql://localhost:3306/coursejdbc
  useSSL: false

# Executar o programa.
  -> Run as Java Application
```
